# Desenvolvimento — Bruxel Piscinas

## Projeto

Laboratório de Programação para Internet · 2026B · Univates

Este projeto dá continuidade ao trabalho de design feito na disciplina ESC 2026A (Grupo F) para o mesmo cliente: um site com e-commerce e um quiz diagnóstico ("Piscinator") que recomenda produtos de tratamento de piscina a partir dos sintomas relatados pelo cliente. Nesta disciplina o grupo assume a etapa de construção, começando por validar com o cliente o que ainda não está resolvido — em especial as regras de negócio por trás das recomendações.

## Cliente

**Bruxel Piscinas** — empresa de manutenção e tratamento de piscinas em Lajeado/RS, no mercado desde 2019 (atividade iniciada em 2015), com loja física inaugurada em 2025. Diferencial declarado: atendimento próximo e orientação técnica baseada na experiência de quem trabalha diariamente com piscinas.
